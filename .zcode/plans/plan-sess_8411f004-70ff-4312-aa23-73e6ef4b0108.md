# Geographic Scope Selector + Level 1 Fix

## Problem 1: Alias Pollution
"Jersey Devil" returns aliases from Scotland because there's no geographic constraint. Need a country/region selector so the LLM searches the right geographic scope.

## Problem 2: Level 1 `suggestedTitle` Error
`suggested_title` is required `String` but LLM sometimes omits it → `missing field 'suggestedTitle'`.

## Solution

### 1. Geographic Scope Selector (Step 1, after Subject Name)
- **Country dropdown** with global coverage (USA, Canada, Mexico, UK, China, Japan, Russia, Australia, etc.)
- **State/Region dropdown** — appears when USA is selected, shows 50 states. Other countries show provinces/regions or free text.
- Both fields feed into the enrichment LLM so it searches the correct geographic scope
- Stored as `geographicScope` string (e.g., "New Jersey, USA")

### 2. Pass Geographic Scope to Enrichment
- `triageEnrich()` → add `geographicScope` param
- `triage_enrich` command → add `geographicScope` param
- `run_level1_enrich()` → add `geographicScope` param, include in LLM prompt
- Update enrichment prompts: "Search for [subject] specifically in [geographicScope]"

### 3. Fix Level 1 `suggested_title`
- Make `suggested_title: Option<String>` in `TriageLevel1Result`
- Frontend: `level1.suggestedTitle || "Untitled Prompt"` as fallback

2. **Step 2**: Answer questions (no error)
