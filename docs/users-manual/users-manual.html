Get Started / Installation

This section guides you through the installation process.

Overview

Prompt Workstation is a local prompt generation engine and catalog workstation. It allows you to create, manage, and triage prompts for various domains such as code, writing, planning, and architecture.

Installation

Prerequisites

Before installing Prompt Workstation, ensure you have the following:

  • Rust: Install the latest version of Rust from rust-lang.org.
  • Node.js: Install Node.js (version 18 or later) from nodejs.org.

Installation Methods

Method 1: Using Tauri CLI
  1. Clone the Repository: 
    git clone https://github.com/your-repo/prompt-workstation.git
cd prompt-workstation
  2. Install Dependencies: 
    npm install
  3. Build the Application: 
    npm run build
  4. Run the Application: 
    npm run tauri dev

    This will launch the application in development mode.

  5. Build for Production: 
    npm run build

    This will generate a production-ready binary in the dist folder.

  6. Launch the Application:
    • On Windows: Navigate to the dist folder and run prompt-workstation.exe.
    • On macOS: Navigate to the dist folder and run prompt-workstation.
    • On Linux: Navigate to the dist folder and run ./prompt-workstation.
Method 2: Manual Build

If you prefer to build the application manually:

  1. Clone the Repository: 
    git clone https://github.com/your-repo/prompt-workstation.git
cd prompt-workstation
  2. Install Dependencies: 
    npm install
  3. Build the Application: 
    npm run build
  4. Run the Application:
    • Use the Tauri CLI to run the application: 
      npm run tauri dev

Installation Path

The application will be installed in your local data directory, typically at:

  • Windows: %APPDATA% auri esources auri-store
  • macOS: ~/Library/Application Support/tauri/resources/tauri-store
  • Linux: ~/.config/tauri/resources/tauri-store

Launching the Application

After installation, launch the application from your desktop shortcut or via the command line.

First Launch

On first launch, the application will seed the catalog with starter prompts. This ensures you have a starting point for your prompts.

Verifying Installation

Open the application and check that the UI loads correctly. You should see the main dashboard with prompts and settings options.

Uninstallation

To uninstall the application, follow the platform-specific instructions below:

  • Windows: Use the standard Windows uninstaller or delete the application files from %APPDATA% auri esources auri-store and the desktop shortcut.
  • macOS: Use the standard macOS uninstaller or delete the application files from ~/Library/Application Support/tauri and the dock icon.
  • Linux: Use the standard Linux uninstaller or delete the application files from ~/.config/tauri and the application menu.

First Launch

This section guides you through the first launch experience.

Overview

After installing Prompt Workstation, this section guides you through the first launch experience.

What Happens on First Launch

Initial Setup

  1. Catalog Seeding:
    • The application automatically seeds the local SQLite database with starter prompts. This ensures you have a starting point for your prompts.
    • Starter prompts include:
      • Rust CLI Tool Builder: A template for generating a Rust CLI tool.
      • Technical Blog Post Outline: A template for creating a structured outline for a technical blog post.
      • System Architecture Review: A template for reviewing an architecture diagram and producing a risk assessment.
  2. Default Configuration:
    • The application loads default LLM settings for freellm with a local endpoint (http://127.0.0.1:31415/v1).
    • Ensure your local LLM service is running if you want to use these defaults.

UI Overview

  • The application opens to the main dashboard with a sidebar on the left and a main content area on the right.
  • The sidebar contains navigation options for:
    • Catalog: Browse and manage prompts.
    • Favorites: View your favorite prompts.
    • Triage: Run the triage engine to categorize and refine prompts.
    • Settings: Configure LLM endpoints and application settings.

Starting Your Work

  1. Open the Catalog View:
    • Click the Catalog option in the sidebar to view and manage your prompts.
    • You will see a list of starter prompts and any prompts you have added.
  2. Edit a Prompt:
    • Click on a prompt to open its details.
    • Modify the prompt title, description, and content.
    • Click Save to update the prompt.
  3. Mark as Favorite:
    • Click the favorite icon next to a prompt to mark it as a favorite.

Verify Application Functionality

  • Ensure that prompts are saved correctly and that the UI updates reflect your changes.
  • Test the LLM integration by navigating to the Settings view and clicking the Test Chat button to verify the active endpoint.
